# 星野 · 手势与彩塑 v22

黑底二十八宿星图，叠加独立的 MediaPipe 手势输入与 28 宿彩塑 2.5D 粒子化形。彩塑使用用户提供并确认有使用权限的四张摄影拼图；未引入参考项目的程序或神像插画。

v22 将用户提供的亢金龙 STL 接入亢宿的真实三维粒子化形：按三角形面积离线采样 120000 个独立表面点与法线，加上 24000 个汇聚流粒子，总绘制仍为 144000 点。真实三维旋转、透视和深度测试替代该宿的 2.5D 图像点云；其余 27 宿保留现有素材。参考用户海报，改用青绿、冰蓝、淡金的细粒子、轻光晕与流动星芒。STL 没有颜色贴图，配色属于艺术演绎。

选择“亢宿”后点击“粒子化形”或按 M。模型自动转动，按住鼠标拖动可连续查看侧面和背面，移手也有转向反馈。生成与展示期间保留鼠标 / 五指独立涟漪、最多五处与自动返回。直接预览：https://owzy00.github.io/wzy/model-qa.html?v=22 ，无需摄像头即可检查三维角度和粒子风格。

## 在线体验

打开 https://owzy00.github.io/wzy/ 即可体验，无需下载。首次进入网页自动请求摄像头权限，允许后即可使用。张掌直接拖动星图，停手即停，把目标移近中央准星；握拳稍停 350 ms 点亮准星附近的星宿，再张掌稳定 180 ms 触发化形。4.8 秒卷云凝像、4.2 秒成形展示、3 秒平滑返回，随后继续环顾。每次化形都需重新握拳。浏览器是否长期记住权限取决于用户的站点权限设置，网页不能绕过拒绝或系统限制。

## 本地开发

使用 Node.js 24，在仓库中先运行 `node scripts/restore-assets.mjs` 还原并校验资源，再运行 `npm run dev`。无需 npm install。

单文件体验版为 `星野-手势与彩塑-v22.html`：内嵌星表、样式、程序和全部点云，键鼠与按钮化形可离线使用。单文件开启摄像头时依赖外部网络资源，摄像头建议在完整包的 localhost 页面使用。

## 主要操作

- 拖动、滚轮、方向键、加减号：浏览星图；V 切换投影，R 重置，1–4 四象，[ / ] 上下宿，F 聚焦。
- W / 手势面板“推动星尘”按钮 / Shift + 拖动：保留独立光粒交互反馈。
- M / “粒子化形”：从已选宿汇聚成对应彩塑。
- 成形后约 4 秒自动回归；Esc / “回到星图”：提前平滑结束。
- 首次授权后自动接入手势；移手环顾、握拳选宿、张掌化形。“手势交互”面板可查看预览、重试或主动关闭摄像头。

生成与成形展示时，任意手指相对手掌单独晃动，在对应指尖位置触发涟漪；整手移动不发波。多指保持独立位置，同时最多五处，同一指尖不重复叠圈。鼠标与键盘仍可使用。

视频仅在本机浏览器处理（默认工作线程，不支持时使用兼容识别），不上传、不录制。收起面板不关闭摄像头；生成与展示均保留手势推理来扰动粒子，期间锁定星图导航与重复触发；离场或切到后台时暂停推理，返回后复用同一会话。点击“关闭摄像头”或离开页面会释放摄像头。

## 开发与验证

```sh
npm run dev
npm test
npm run build
```

静态发布目录为 `dist/`。构建会生成单文件并检查脚本、数据映射、点云和模型资源。`qa.html` 可运行不申请摄像头的真实模型自检。

MediaPipe：`@mediapipe/tasks-vision` 1.1.1，CPU Worker。模型与依赖来源 / 校验值见 `dist/vendor/mediapipe/provenance.json`。只有图像素材的 27 宿仍为近似深度演绎；亢宿使用真实 STL 表面点。STL 原文件 135585484 字节、2711708 个三角面；发布点云 JSON 1920609 字节（gzip 约 1.24 MB），网页不加载原始 STL。原始模型形体与没有贴图会限制可见细节。

天文坐标、连线和装饰粒子相互隔离；星表对象冻结。数据来源和许可见 `dist/data/provenance.json`、`dist/data/NOTICE.txt`。彩塑来源、裁切框、原图 SHA-256 与宿名映射见 `dist/data/statues.json`；原图切片位于 `dist/assets/statues/`。

实现、误触防护及使用边界见 [PHASES-2-3.md](PHASES-2-3.md)，测试记录见 [TESTING.md](TESTING.md)，配色历史见 [THEME.md](THEME.md)。真实摄像头识别率、不同手型 / 光照和低端设备性能仍需实机验收。

重新提取点云需安装 Python 的 Pillow 与 NumPy，并运行 `python scripts/extract-statues.py --input-dir <原始四张拼图目录>`。原始文件名对应记录保留在脚本中，生成结果覆盖 dist/data/statues.json。依赖重新下载脚本为 scripts/download-mediapipe.py，固定版本和模型来源。
